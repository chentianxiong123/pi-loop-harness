# 软件工程哲学：意图驱动的分形软件工厂

> pi-loop-harness 的思想底座。
> 提炼日期：2026-08-27
> 本构的工程世界观：**物理隔离优于逻辑隔离，哈希锁死优于版本协商，AI loop 接管一切可自动化的心智劳动，人只保留定义意图与确认契约两种创造行为。**

---

## 1. 核心信条

### 1.1 人月神话是敌人的圣经
沟通爆炸、集成地狱、概念完整性坍塌都是真实的，但旧解法错了——它试图在单体里优化协作。我们选择**直接消灭协作的需求**：能不下桥就不下桥。

### 1.2 物理隔离优于逻辑隔离
任何靠人的纪律维持的边界（代码规范、设计模式、模块边界）都是脆弱的。唯一可信的硬度来自物理定律：**进程边界、网络协议、编译期检查、哈希锁死**。

### 1.3 人的心智是瓶颈
复用、搜索、沟通、决策，全在消耗心智。一切可以自动化、编译化、去重化的，都交给机器。**人只负责创造。**

### 1.4 商业软件是混沌的具象化
HTML/CSS/JS、V8、Electron、GC……是历史包袱的堆砌，是靠补丁维持的臃肿"平台税"。抵抗的方式不是改良，是拆开重装。

---

## 2. 架构法则：分形解耦

```
原子组件 → 微CLI组件 → 微程序组件 → 微服务组件 → 微系统组件
```

- 每个组件编译成**单一静态二进制**（Go/Rust），零运行时依赖。
- 每个组件跑在**自己的沙箱/进程/容器**里，崩溃不扩散。
- 每个组件只通过**预先定义的接口协议**对外通信（gRPC / HTTP / 文件描述符）。
- **没有共享内存，没有隐式依赖，没有全局状态。**

> 修正：物理隔离说的是**进程边界**，不是语言纯洁性。harness 引擎在 agent 侧用 TS（解释运行、贴近生态），系统侧用 Go（编译、硬隔离、watchdog），两者分层不冲突。

---

## 3. 包管理法则：哈希锁死 + 可复现

1. **百分百可复现是底线**：依赖声明里写哈希，不是版本号；整个构建环境的输入全部锁死，任何机器都能复现。
2. **包即 Git 仓库**：没有中心化注册表；一个包 = 一个仓库，身份 = 内容哈希；发现靠全局依赖图的可及性分析，不靠搜索。
3. **包坏了？Fork & Occupy**：一秒钟分叉，自行修复，发布为新哈希。绝不向原维护者跪求沟通。
4. **闭源包？物理隔离**：放进沙箱，用行为契约测试验证，永远持有开源替代；一旦违约，一个构建周期内完成热替换。

---

## 4. 编译器法则：机器消化混沌（愿景层）

- **编译器去重**：随手写、写最直白的代码，编译器在中间表示层面自动合并语义同构的实现。
- **全局同构图**：所有公开代码的语义签名构成可搜索、可验证的图，写码时编译器自动推荐语义匹配的原子包。
- **栈式分配替代 GC**：UI 生命周期与函数栈严格对齐，页面关闭瞬间整块内存线性释放。

> 诚实标注：本章是**研究愿景，不是当前工程规格**。语义级去重、全局同构图仍需长期探索，先以显式的小组件复用落地。

---

## 5. UI 法则：把运行时降级成外壳（渐近执行）

- **HTML/CSS/JS 是文档时代的遗产**，只配当启动器；默认渲染改为 SSR（templ/HTMX），删除 JS/SPA 仪式 = 现在就执行。
- **浏览器最终应被肢解**：外壳用 Rust 写、秒开，内核 WebGPU 直驱显卡，UI 是 GPU 纹理与着色器（研究终局，不阻塞当前进度）。
- **GPU 功耗哲学**：默认休眠、事件驱动、精确重绘变化区域，没有 60 帧死循环；动画结束 GPU 归零。

---

## 6. 开发哲学：AI Agent 原生 Loop

前 AI 时代这套架构是精英的屠龙之术，无法规模化。AI 解决了两个根本问题：

- **全知全能的架构师**：AI 扫描全局哈希图，推荐语义匹配的原子。
- **不知疲倦的实现者**：AI 写代码、跑合规测试、编译成 WASM、返回哈希。

**人的角色：定义意图**——"我要一个能处理音频流的组件，输入 PCM，输出 JSON 频谱"。AI 去执行，人只在关键节点确认契约。

### 6.1 承重墙：loop + harness

哲学没有约束就是"更多二进制的混沌"。**隔离是安全性，哈希是信任，loop 是那只手。**
工具门禁、输出契约、上下文锁让每个崩溃可孤立、每个节点可信任——这正是项目框架要提供给 AI loop 的土地。

---

## 7. 一句话总结

> 把人从机械、可预测、可自动化的一切心智劳动中解放出来，只留下**定义意图与确认契约**这两件创造之事；其余交给哈希锁死的依赖图、进程边界和永不疲倦的 loop。
